Mã nguồn và tài liệu đồ án kiểm thử các chức năng tài khoản, tìm kiếm, giỏ hàng và thanh toán OpenCart.

| Thư mục | Nội dung |
| --- | --- |
| [black-box/](black-box/) | `BlackBoxTestingOpenCartDemo_LaHieuPhong` và bản mở rộng `La_Hieu_Phong` |
| [white-box/](white-box/) | Bộ `WhiteBoxTestingOpenCartDemo_LaHieuPhong` dùng PHPUnit và Selenium PHP |
| [selenium-prototype/](selenium-prototype/) | Repository Selenium OpenCart thử nghiệm profile và user agent |
| [documents/](documents/) | `Project Details.docx`, đề cương phạm vi và công cụ kiểm thử |
| [presentation-drafts/](presentation-drafts/) | Slide nhóm Phong, Vũ, Quân, Nguyên; còn nội dung template ở các slide cuối |
