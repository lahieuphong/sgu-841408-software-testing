# Testing tools

| Directory | Contents |
| --- | --- |
| [chromedriver-mac-arm64/](chromedriver-mac-arm64/) | One archived macOS ARM64 ChromeDriver binary with its license and third-party notices |
| [selenium-java-4.27.0/](selenium-java-4.27.0/) | Original Selenium Java JAR distribution, dependencies, source JARs and license files |
| [report-assets/](report-assets/) | Shared stylesheet for saved pytest HTML reports |

The five identical bundled ChromeDrivers are consolidated into one distribution. Coursework scripts use Selenium Manager or WebDriver Manager unless configured otherwise; the archived driver version still needs to match the browser when used explicitly.

Dependency manifests and license files remain with independent suites or distributions even when their text overlaps.
